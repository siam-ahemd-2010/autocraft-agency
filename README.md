# AutoCraft Agency

A premium automation agency website built with Next.js, TypeScript, Tailwind CSS, GSAP, Three.js, and Supabase.

## Features

- **Premium Design**: Glassmorphism, orange-red gradients, smooth animations
- **3D Visuals**: Interactive Three.js automation visual in hero
- **Smooth Scrolling**: Lenis + GSAP ScrollTrigger integration
- **User Authentication**: Simple phone + password login
- **Point System**: User points balance with history
- **Admin Dashboard**: Manage user points easily
- **Payment Modal**: Manual payment instructions

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- GSAP (ScrollTrigger)
- Three.js
- Lenis (Smooth Scroll)
- Supabase (Backend)
